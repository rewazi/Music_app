# Which methodology would you use: Waterfall, Scrum, or Incremental? Why?

I would choose Scrum.  
Because the client’s requirements are constantly changing, Scrum is well suited for flexible development. The team can work in short sprints, regularly present results to the client, and quickly implement changes to the project. This reduces the risk of creating an application that does not meet the client’s expectations.

# What would happen if you chose the Waterfall model and the client changed the requirements in the second month?

If the waterfall model is chosen and the client changes the requirements in the second month, the following problems may occur:

- completed work would need to be redone;
- development time would increase;
- additional costs could appear;
- the application architecture might require changes;
- part of the completed work could become useless.
