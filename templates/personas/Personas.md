## Scenarios

### Scenario 1 — Alex Johnson

- **Actor:** Alex Johnson
- **Motivation:** Wants to listen to music quickly between classes
- **Goal:** Start playing a specific song immediately
- **Actions:**
    1. Opens the app
    2. Logs in
    3. Uses search
    4. Selects a song
    5. Starts playback
- **Result:** Music starts quickly without unnecessary steps

---

### Scenario 2 — Maria Petrova

- **Actor:** Maria Petrova
- **Motivation:** Wants to organize her music after work
- **Goal:** Create a playlist and add songs
- **Actions:**
    1. Opens the app
    2. Navigates to saved tracks
    3. Creates a new playlist
    4. Adds selected songs
- **Result:** Playlist is created and ready for future listening

## User Stories (Prioritized)

1. **[High Priority]**  
   As a user, I want to log in quickly, so that I can access the app without delay.

2. **[High Priority]**  
   As a user, I want to search for songs by title or artist, so that I can quickly find music.

3. **[High Priority]**  
   As a user, I want to start playback with one tap, so that I can listen instantly.

4. **[Medium Priority]**  
   As a user, I want to save favorite tracks, so that I can access them later.

5. **[Medium Priority]**  
   As a user, I want to create playlists, so that I can organize my music.
