# System Requirements

## Functional Requirements

- The user must be able to register  
- The user must be able to log in  
- The user must be able to search for songs and albums  
- The user must be able to create and manage playlists  
- The user must be able to update their personal data  

## Non-Functional Requirements

- Access to the login must be blocked for 2 minutes after 5 failed login attempts  
- Access to playlists must be achievable within 2 actions and take no more than 10 seconds  
- Adding a single song to a playlist must be achievable within 3 actions and take no more than 15 seconds
